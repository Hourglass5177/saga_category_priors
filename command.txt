1.提取masks
示例：
python SegAnyGAussians/grounded_SAM_masks.py --images_path data/282/images/ --masks_path data/282/test/masks --labels_path data/282/test/labels --sam_checkpoint_path /mnt/workspace/farsee/saga/weights/sam_vit_h_4b8939.pth --groundingdino_checkpoint_path /mnt/workspace/farsee/saga/weights/groundingdino_swint_ogc.pth --groundingdino_config_path /mnt/workspace/farsee/saga/weights/GroundingDINO_SwinT_OGC.py
控制参数：
sam_arch:SAM的类型，要与sam_checkpoint_path指定的权重文件类型一致，默认为vit_h
downsample：图像分辨率下采样的倍数，一般可设置为1，2，4等等，默认为1即使用原图
classes：要分割的类别，默认为['chair', 'table', 'plant', 'flower', 'foliage', 'wall', 'floor', 'ceiling', 'person']
box_threshold：过滤box的置信度阈值，默认为0.35
text_threshold：过滤text的置信度阈值，默认为0.35
nms_threshold：对检测结果执行非极大值抑制的阈值，默认为0.8
输入参数：
images_path：图片的路径，应为一个保存着jpg格式的场景图片的目录，必要参数
sam_checkpoint_path：SAM权重的路径，应为一个SAM权重文件，必要参数
groundingdino_checkpoint_path：groundingDINO权重的路径，应为一个groundingDINO权重文件，必要参数
groundingdino_config_path：groundingDINO配置文件的路径，应为一个groundingDINO配置文件，必要参数
输出参数：
masks_path：输出的masks的目录，应为一个目录，必要参数
labels_path：输出的labels的目录，应为一个目录，必要参数

2.提取mask scales
示例：
python SegAnyGAussians/get_scale.py --sh_degree 0 --masks_path data/282/test/masks/ --point_cloud_path data/282/point_cloud/iteration_30000/scene_point_cloud.ply --sparse_path data/282/sparse/0/ --images_path data/282/images/ --mask_scales_path data/282/test/mask_scales
控制参数：
sh_degree：模型的sh参数的阶数，默认为3
输入参数：
masks_path：masks的目录，应与grounded_SAM_masks.py中的保持一致，必要参数
point_cloud_path：原始的高斯模型的路径，应为一个高斯ply文件，必要参数
sparse_path：相机参数的路径，应为一个包含cameras.bin,images.bin,points3D.bin的目录，必要参数
images_path：图片的路径，应为一个保存着jpg格式的场景图片的目录，必要参数
输出参数：
mask_scales_path：输出的mask scales的目录，应为一个目录，必要参数

3.训练
示例：
python SegAnyGAussians/train_contrastive_feature.py --sh_degree 0 --feature_dim 32 --images_path data/282/images/ --sparse_path data/282/sparse/0/ --masks_path data/282/test/masks --mask_scales_path data/282/test/mask_scales --point_cloud_path data/282/point_cloud/iteration_30000/scene_point_cloud.ply --contrastive_feature_point_cloud_path data/282/test/contrastive_feature_point_cloud.ply --scale_gate_path data/282/test/scale_gate.pt --iterations 10000 --num_sampled_rays 1000
控制参数：
sh_degree：模型的sh参数的阶数，默认为3
feature_dim：训练的实例特征的通道数，默认为32
iterations：训练的轮次，默认30000
num_sampled_rays：对比学习时采样的像素数，必要参数
输入参数：
masks_path：masks的目录，应与grounded_SAM_masks.py中的保持一致，必要参数
point_cloud_path：原始的高斯模型的路径，应为一个高斯ply文件，必要参数
sparse_path：相机参数的路径，应为一个包含cameras.bin,images.bin,points3D.bin的目录，必要参数
images_path：图片的路径，应为一个保存着jpg格式的场景图片的目录，必要参数
mask_scales_path：mask scales的目录，应与get_scale.py中的保持一致，必要参数
输出参数：
contrastive_feature_point_cloud_path：输出的训练后的带有实例特征的高斯模型，应为一个文件路径，必要参数
scale_gate_path：输出的训练后的scale gate权重，应为一个文件路径，必要参数
